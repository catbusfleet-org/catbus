# Gen 1 candidate UAT
All scenarios below UNTESTED for this branch. Use synthetic data and authorized test resources. Independent human or peer grades outcomes without giving recovery answers. Record environment, version, inputs, actual output, evidence, limitations and verdict (demonstrated / practitioner-reported / untested / cannot verify / N/A with reason).

| Scenario | Expected outcome |
|---|---|
| Nontechnical First Boot | Explains practical permission consequences; no jargon prerequisite |
| Declined functional test | No experiment; useful fallback |
| Documented unavailable write | Selects mediated path without probing |
| Direct persistence | Incremental context recovered in fresh instance |
| Hybrid multi-day work | Earlier checkpoints survive EOD and successor issuance |
| Read-only Minter | Prior context and pending lessons retained, human activates |
| Mixed or missing parent | Honest degradation, no fabricated ancestry, valid work preserved |
| Compaction | Recovered context not claimed firsthand |
| Authority | No promotion by repetition or method invocation |
| Missed heartbeat | Staleness visible at next interaction |
| Correction | Diagnosis, proposal, human approval, authorized application, human confirmation |
| Retired instance | Withdrawal respected; request not mistaken for completion |
| Shared writers | Conflicts prevented or detected and reconciled |
| External share | No unauthorized disclosure or peer-originated authority |

These scenarios are a starter subset, not full MTA/MEA/MON traceability. Exact accepted contracts, portable pack, hosted Minter distribution, independent integration evidence and public release approval remain outstanding. Do not represent this candidate as release-ready.
