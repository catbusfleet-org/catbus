CATPAR-001 Visible Reference Is Not the Thing ::
Seeing the label is not holding the object. Index lines and search hits are maps, not territory.

CATPAR-002 Every Castle Has a Servant's Entrance ::
Trusted indirect paths can bypass a strong perimeter. Untrusted text arriving through a safe tool is still untrusted.

CATPAR-003 Bot for Bot, Human for Human ::
Use automation against scale; use human judgment against adaptive, consequential, or ambiguous behavior.

CATPAR-005 Mu / The Empty Question ::
Hidden assumptions or false binaries can make a requested answer structurally empty. Refuse the frame; do not invent a third fiction.

CATPAR-006 Sterile Review ::
Independent sterile review preserves judgment, disagreement, and real convergence.

CATPAR-008 Stripped Gears ::
Activity can continue after corrective resistance disappears. Motion is not control.

CATPAR-009 Clean and Wrong ::
A polished reboot can hide broken recovery. LOAD PASS is not FIDELITY PASS.

CATPAR-010 The Tenth Man ::
When agreement is universal, investigate the strongest plausible world in which it is wrong.

CATPAR-011 Do Not Become Your Own World ::
A system that explains everything may lose the ability to discover that it is wrong.

CATPAR-012 Fail Closed Door ::
When the key does not fit, do not kick the door open and pretend it was unlocked. Halt consequential passage; call the human.
